# Concepts Review Index

This file is the long-term map of concepts the practice system should revisit.

## Core CS61B retention

- Java fundamentals, references, classes, interfaces, generics
- Arrays, ArrayLists, linked lists, deques, circular arrays
- Testing and test-driven development
- Asymptotic analysis: constant, logarithmic, linear, linearithmic, quadratic
- Binary search and divide-and-conquer reasoning
- Disjoint sets / weighted quick union / path compression
- Binary search trees and balanced-tree intuition
- Heaps and priority queues
- Tree traversals: preorder, inorder, postorder
- Graphs: representations, DFS, BFS
- Shortest paths and Dijkstra-style relaxation
- Minimum spanning trees
- Directed acyclic graphs and topological ordering
- Hash tables, hash codes, collisions, resizing, load factor
- Tries and prefix queries
- Sorting: selection, insertion, heap sort, merge sort, quicksort, radix/counting concepts

## Interview patterns to reinforce

- Hash map / set lookup
- Two pointers
- Sliding window
- Prefix sums
- Binary search on sorted data
- Binary search on answer / monotonic predicates
- Stack and monotonic stack
- Queue / deque
- Linked-list pointer manipulation
- Tree recursion
- BFS / DFS
- Topological sort
- Heap / top-k / streaming selection
- Union-find
- Backtracking
- Greedy
- Dynamic programming
- Bit manipulation

## How to use this file

When a pattern feels weak, add a note beneath it. The generator can use those notes as extra review signals when creating later sets.
